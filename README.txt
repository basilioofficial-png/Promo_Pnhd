PNHD — файлы промостраницы

ЗАГРУЗКА НА ХОСТИНГ
1. Распакуйте архив.
2. Загрузите index.html, style.css, app.js, data.js, artwork.js, header.css, header.js и папку assets в корневую папку сайта (обычно public_html).
3. Откройте сайт по HTTPS. Node.js, npm и база данных не требуются.

ФАЙЛЫ
index.html — разметка и тексты.
style.css — оформление и адаптивность.
app.js — калькулятор, выбор моделей, скачивание конфигурации.
data.js — 13 моделей, 53 цветовых варианта, тарифы.

Рекламные версии: ?offer=price, batch, deadline, team, quality.
Шрифт Golos Text загружается из Google Fonts; при недоступности используется Arial.

ВАЖНО
Это версия для согласования. Приём заявок и CRM не подключены.
Фото отсутствуют намеренно. Полная стоимость требует подтверждения условий.
Метатег noindex,nofollow оставлен для тестовой версии. Перед публичным запуском согласуйте цены, контакты, юридические тексты и индексацию.

ШАПКА САЙТА
header.css и header.js — оформление, выпадающие меню и мобильная навигация по образцу pnhd.ru.
Папка assets — оригинальный SVG-логотип и шрифты Futura PT (Book и Bold), сохранённые локально с pnhd.ru / static.tildacdn.com. При загрузке на хостинг загрузите эти файлы вместе с остальными.
Ссылки шапки ведут в соответствующие разделы основного сайта; кнопка «Проконсультироваться» открывает форму на pnhd.ru.

МАКЕТ И ОЦЕНКА ЦВЕТОВ
artwork.js — загрузка и локальная оценка цветов макета в калькуляторе. Загрузите этот файл на хостинг вместе с app.js.
Поддерживаются PNG, JPG и WebP до 20 МБ и 100 мегапикселей. Изображение обрабатывается только в браузере; сервер, отправка файла и CRM не задействованы.
Близкие оттенки объединяются; прозрачные пиксели не учитываются. Белый фон можно исключить флажком. Фото, градиенты, мелкие детали и подложка требуют проверки производства.
Кнопка «Применить к расчёту» переносит оценку в параметры печати, если число цветов укладывается в лимит: до 8 для обычных форматов, до 2 для ручника. Число красок можно изменить вручную.
Имя файла и оценка попадают в скачиваемую конфигурацию; само изображение нужно передать менеджеру отдельно.
Проверка в браузере (требуется установленный Playwright): CHROMIUM_PATH=/usr/bin/chromium node tests/artwork.smoke.cjs. Без CHROMIUM_PATH используется браузер Playwright по умолчанию.

ПРОМО И РАЗМЕРЫ
Первый экран показывает пример «Футболки с нанесением от 464,40 ₽»: белая Regular 180, А4, 1 цвет, 1000 шт. Цена примера вычисляется из тарифов data.js. Варианты ?offer=price,batch,deadline,team,quality содержат конкретное предложение.
Для каждой из 13 моделей в data.js заданы sizes и отдельный объект stock. Остатки пока демонстрационные: по 100 шт. каждого размера, без подключения склада и резервирования.
Количество вводится по размерам. Ввод общего тиража и быстрые кнопки распределяют его поровну по размерам с учётом stock. Превышение остатка, дробные и отрицательные значения блокируют расчёт. Минимум — 50 изделий в сумме, не на каждый размер.
При смене модели её выбор размеров хранится отдельно в текущей вкладке до перезагрузки; для новой модели выбор начинается с нуля. Изменение цвета сохраняет размеры. Разбивка добавляется в диалог и скачиваемую конфигурацию.
Проверка: CHROMIUM_PATH=/usr/bin/chromium node tests/sizes-offers.smoke.cjs
